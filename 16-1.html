三、四个比喻记住关键区别

数组的盒子会“挪位置”，索引会跟着变

排队买奶茶：push / pop

push 是新人站到队尾，pop 是队尾的人离开。 只在末端操作，其他人的索引都不用变，最省事。

有人插队：unshift / shift

unshift 在队首插一个人，shift 让队首的人走掉。 后面每个人的索引都要 +1 或 -1，所以比 push / pop 慢。

复印还是剪贴：slice / splice

slice 是“复印一段带走”，原数组一根头发都不少； splice 是“拿剪刀在原数组上剪掉或塞进一段”，原数组会变。

流水线：map / filter / reduce

map 给每个盒子贴一张新标签，filter 只留下合格的盒子， reduce 把所有盒子压成最后一个结果——三者都返回新值，不动原数组。
