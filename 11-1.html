Web 前端长度单位

CSS 中常用的长度单位一览 — 绝对单位与相对单位

像素

px

最常用的绝对单位。1px 对应屏幕上的一个物理像素（在高 DPI 屏幕上可能对应多个物理像素）。适合边框、阴影等需要精确控制的场景。

width: 100px; height: 60px

相对父元素字体大小

em

相对于当前元素的 font-size。如果当前元素 font-size 为 16px，则 1em = 16px。常用于 padding、margin 等需要与文字大小成比例的场景。

width: 10em; height: 3em（font-size: 16px）

相对根元素字体大小

rem

相对于根元素（html）的 font-size，默认 16px。与 em 不同，rem 不受嵌套影响，更适合响应式布局和统一间距系统。

width: 8rem; height: 3rem

百分比

%

相对于父元素的对应属性值。宽度百分比相对于父元素宽度，高度百分比相对于父元素高度。是实现流式布局的核心单位。

width: 60%; height: 50px

视口宽度

vw

1vw = 视口宽度的 1%。视口指浏览器窗口的可见区域。常用于全屏布局、大标题字体等需要与屏幕宽度联动的场景。

width: 30vw; height: 50px

视口高度

vh

1vh = 视口高度的 1%。常用于需要占满屏幕一屏的场景，如 100vh 实现全屏 Banner。

width: 120px; height: 15vh

视口较小值

vmin

1vmin = vw 和 vh 中较小值的 1%。在横竖屏切换时能保持元素比例稳定，适合正方形元素和响应式图标。

width: 20vmin; height: 20vmin

视口较大值

vmax

1vmax = vw 和 vh 中较大值的 1%。与 vmin 配合使用，可以创建更灵活的响应式布局方案。

width: 15vmax; height: 40px

字符宽度

ch

1ch 等于当前字体中 "0" 字符的宽度。常用于限制文本容器宽度，如设置 max-width: 60ch 提升可读性。

width: 20ch; height: 50px

厘米

cm

物理长度单位，1cm = 37.8px ≈ 96dpi 下的 1 厘米。主要用于打印样式表（@media print），屏幕显示时精度有限。

width: 5cm; height: 40px

毫米

mm

1mm = 1/10 cm。与 cm 一样属于物理单位，主要用于打印排版场景。

width: 50mm; height: 40px

英寸

in

1in = 2.54cm = 96px。CSS 中定义的绝对物理单位，屏幕显示时按 96dpi 换算，打印时按实际英寸输出。

width: 2in; height: 40px

点

pt

1pt = 1/72 in ≈ 1.333px。源自印刷行业，在 CSS 中主要用于打印样式或需要与 Word 文档字号对应的场景。

width: 144pt; height: 40px

派卡

pc

1pc = 12pt = 1/6 in。印刷行业单位，在 Web 开发中极少使用，主要用于打印样式表。

width: 12pc; height: 40px
