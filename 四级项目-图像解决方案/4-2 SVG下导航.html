两种图像解决方案的对比

同一个下导航，两种技术路线：字体图标把图形当作字符，SVG 把图形当作矢量元素。

对比项 方案一：字体图标（iconfont） 方案二：SVG（symbol + use）
引入方式 @font-face 加载 ttf / woff 字体文件 内联 <symbol> 定义，<use> 引用
HTML 写法 <i class="guan_icon guan_icon_heart"></i> <svg><use href="#guan_sym_heart"></use></svg>
大小控制 CSS font-size CSS width / height
颜色控制 CSS color（字符继承文字颜色） CSS fill: currentColor 继承 color
多彩图标 不支持，一个字形只能单色 支持，可给不同 path 设置不同填充
抗锯齿 字形栅格化，极端字号下略糊 始终按矢量渲染，任意缩放都清晰
本页做法 下导航随内容流排列，宽度 100% 下导航 position: fixed 固定底部，宽度 100%

核心代码要点

  • 图标仓库是一个 width: 0; height: 0; overflow: hidden 的内联 svg，既不占布局，也不需要额外请求图片文件。
  • 每个 <symbol> 用 viewBox="0 0 100 100" 统一坐标系，因此同一份路径可以被任意尺寸的 <use> 复用。
  • .guan_tab_svg { fill: currentColor } 让 SVG 的颜色跟着 color 走，选中态只需切换 .guan_tab--on 的文字颜色。
  • position: fixed; left: 0; right: 0; bottom: 0 实现固定下导航，配合 padding-bottom: env(safe-area-inset-bottom) 适配刘海屏。
  • body 预留 padding-bottom，避免页面最后一屏内容被固定导航遮住。
