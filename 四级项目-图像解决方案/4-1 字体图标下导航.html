核心代码要点

  • @font-face 声明 guan_iconfont，优先加载体积更小的 woff，失败时回退 ttf，文件均放在本地 font 目录，不引用在线字体。
  • .guan_icon 统一设置 font-family、line-height: 1、font-synthesis: none，保证图标不会被合成加粗而变形。
  • 每个图标用 ::before { content: "\e00x" } 输出私有区字符，HTML 里只写一个 <i> 标签。
  • .guan_tab { flex: 1 1 0 } 让 5 个导航项在任何视口下都严格等分，配合 min-width: 0 与文字省略，窄屏也不会把导航撑破。
  • 图标颜色直接继承 color：未选中 #8A8A8A，选中态加 .guan_tab--on 变品牌红 #C20C0C。
