四级项目 · 图像解决方案

为三级项目「网易云音乐」设计移动端下导航，分别用字体图标与SVG两种图像方案实现， 导航均为自适应宽度，SVG 方案额外实现底部固定效果；全部使用原生 HTML + CSS，不引入任何第三方库与在线 CDN。

  • 方案一

    字体图标下导航

    @font-face 加载本地 guan_iconfont 字体，图标即文字；font-size 控大小、color 控颜色，5 项 flex: 1 1 0 自适应均分。

    进入页面

  • 方案二

    SVG 下导航

    内联 symbol + use 复用矢量路径，fill: currentColor 换色，position: fixed 固定在视口底部，同样自适应宽度。

    进入页面

  • 图标库

    图标总览

    11 个图标的字体图标 / SVG 双方案对照表，附带 16~48px 尺寸与 5 种颜色的使用效果。

    进入页面

实验要求与完成情况

  • 获得图标：参考 iconfont.cn 图标库造型，自绘 11 个 100 × 100 栅格的矢量图标，导出为字体文件与 SVG 路径两种格式，图标不要求与原型完全一致。
  • 自适应宽度下导航：两个方案都使用 flex: 1 1 0 + min-width: 0，在 320 / 375 / 414 / 768 / 1440px 视口下均等宽均分，文字不换行不溢出。
  • 技术上有区别：方案一是字体图标，方案二是 SVG；前者靠字形、后者靠矢量图形，两者在大小、颜色、多色支持上的差异见 4-2 页对照表。
  • 固定效果：三级项目的下导航属于固定在屏幕底部的导航，SVG 方案用 position: fixed; bottom: 0 实现，并用 env(safe-area-inset-bottom) 适配刘海屏。
  • 测试：以 Edge（Chromium）为主，在 390px / 768px / 1440px 三种视口下逐一检查，兼容写法上保留了 -webkit- 前缀与字体回退。
