JavaScript 程序结构演示

顺序结构 / 条件结构（if-else、switch）/ 循环结构（for、while、do-while）

一、顺序结构
程序从上到下逐条执行
var guan_a = 10; var guan_b = 3; var guan_sum = guan_a + guan_b; // 13
二、条件结构（if / else）
根据条件成立与否执行不同分支
var guan_score = 85; if (guan_score >= 90) { guan_grade = "优秀"; } else if (guan_score >= 80) { guan_grade = "良好"; } else if (guan_score >= 60) { guan_grade = "及格"; } else { guan_grade = "不及格"; }
三、条件结构（switch）
多分支匹配，比连续 if-else 更清晰
var guan_day = 3; switch (guan_day) { case 1: guan_name = "星期一"; break; case 3: guan_name = "星期三"; break; default: guan_name = "其他"; }
四、循环结构（for / while / do-while）
for 求 1~100 累加和；while 求 5 的阶乘；do-while 至少执行一次
var guan_total = 0; for (var guan_i = 1; guan_i <= 100; guan_i++) { guan_total += guan_i; } var guan_fact = 1, guan_n = 5; while (guan_n > 1) { guan_fact *= guan_n; guan_n--; } var guan_k = 1; do { guan_k++; } while (guan_k <= 5);
五、循环嵌套：九九乘法表
外层 for 控制行，内层 for 控制列
